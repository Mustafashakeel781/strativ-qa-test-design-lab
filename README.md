# Strativ QA Test Design Lab

This repository contains my QA test design work for five fictional requirements.

## Features Tested

1. User Registration
2. Seat Requests
3. AI Message Limits
4. Image Upload
5. Task Status Transitions

## Testing Coverage

The project covers:

- Positive Testing
- Negative Testing
- Boundary Value Analysis
- Equivalence Partitioning
- State Transition Testing
- Risk-Based Testing
- Coverage Gap Identification

## Test Documentation

Detailed test scenarios and test cases have been created for each assigned feature.

## Project Goal

The purpose of this project is to practice converting business requirements into practical QA test scenarios and detailed test cases.

## AI Disclosure

AI assistance was used for learning, structuring and reviewing test documentation. The final test documents were reviewed and understood by me.
